# Sample swing videos

Run.bat copies these into the emulator's photo library, so you can try the app with **Upload from library** right away. Each one is a different golfer, filmed the way people really film swings: different angles, a hand-held camera, a practice swing first.

You don't have to get the camera angle right. If the video clearly shows a different angle from the one you picked, the app switches and tells you.

| File | Golfer | Camera | Notes |
|---|---|---|---|
| `sample_swing_face_on_with_sound.mp4` | Woman, iron | Face-on | Slow motion, with a ball-strike sound so impact is found from the sound |
| `sample_face_on_junior.mp4` | Junior, iron | Face-on (low angle) | |
| `sample_down_the_line_with_sound.mp4` | Man, iron | Down-the-line | Real sound of the ball strike |
| `sample_down_the_line_driver.mp4` | Man, driver | Down-the-line | |
| `sample_down_the_line_woman.mp4` | Woman, iron | Down-the-line | Slow motion |
| `sample_side_on_senior_hand_held.mp4` | Senior, iron | Angled side view | Hand-held camera that pans with the golfer |
| `sample_from_behind.mp4` | Man, iron | From behind | Forward press before the takeaway |
