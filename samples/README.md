# Sample swing videos

Run.bat copies these into the emulator's photo library, so you can try the app with **Upload from library** right away.

- `sample_swing_face_on.mp4`: pick **Face-on** in the app.
- `sample_swing_down_the_line.mp4`: pick **Down-the-line** in the app.

Both are cut from [Suvichaya Vinijchaitham Golf Swing Slow Mo 2026](https://commons.wikimedia.org/wiki/File:Suvichaya_Vinijchaitham_Golf_Swing_Slow_Mo_2026.webm) by Hut2026 on Wikimedia Commons, released under CC0 (public domain).
